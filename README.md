# KAMANJAMIX VIDEO STUDIO V2 (Windows 10/11، Electron)

**الجديد في V2** (دون حذف أي ميزة سابقة ودون تغيير التصميم):
- **مزامنة الشفاه الذكية:** تحلّل طيف الصوت لحظياً (نطاقات F1/F2 والحروف الاحتكاكية) فتتحكم بفتح الفم واتساعه واستدارته. تعمل دون إنترنت ودون نماذج ثقيلة، وتناسب الأجهزة بكرت رسوم مدمج و8GB. يمكن إيقافها من خانة «مزامنة الشفاه الذكية».
- **تصدير أثبت للأغاني الطويلة:** في نسخة EXE تُكتب أجزاء التسجيل على القرص مباشرة بدل تخزينها في الذاكرة. تُرتّب الكتابات بالتسلسل، وينتظر التطبيق وصول آخر جزء من MediaRecorder وانتهاء تدفق الملف فعلياً قبل إظهار رابط التحميل؛ لم يعد يعتمد على مهلة ثابتة قصيرة.
- **جودة التصدير:** 1080p بمعدل 12 Mbps و720p بمعدل 8 Mbps، وصوت 192 kbps.
- **MP4 وWebM** وكلمات Karaoke/LRC وحفظ المشاريع وفتحها.
- اختبار ذاتي موسّع يتحقق من المزامنة والتصدير أثناء البناء على GitHub، وينتظر اكتمال التصدير ثم يتحقق من وجود ملف غير فارغ.

**ملاحظة صريحة:** التصدير ما زال بالوقت الحقيقي (مدة الملف = مدة الأغنية). التصدير الأسرع من الوقت الحقيقي مخطط للمرحلة التالية.

# KAMANJAMIX VIDEO STUDIO: نسخة Windows (Electron)

تطبيق سطح مكتب يعمل على Windows 10/11 (64 بت)، ويحوي نفس KAMANJAMIX VIDEO STUDIO دون أي حذف أو تغيير في الواجهة أو الوظائف.
بعد التثبيت يعمل **دون إنترنت ودون Node.js ودون متصفح**.

## ما الذي في هذا المجلد

| الملف / المجلد | الغرض |
|---|---|
| `app/kamanjamix-video-studio-standalone.html` | **النسخة المرجعية المُصلَحة** التي يشغّلها التطبيق |
| `app/multi-file/` | النسخة المتعددة الملفات (مُصلَحة أيضاً)، محفوظة ومضمّنة في التثبيت، لكن التطبيق لا يشغّلها |
| `main.js` | غلاف Electron: نافذة التطبيق وإعدادات الأمان والعمل دون اتصال |
| `package.json` | إعدادات المشروع والبناء (اسم التطبيق، الأيقونة، المثبّت) |
| `build/icon.ico` و`icon.png` و`icon.svg` | أيقونة التطبيق |
| `BUILD.bat` | بناء المثبّت على جهاز Windows بنقرتين |
| `.github/workflows/build-windows.yml` | بناء المثبّت تلقائياً على GitHub بلا تثبيت أي شيء عندك |
| `GITHUB-WORKFLOW-COPY/build-windows.yml` | نسخة من ملف GitHub Actions في مجلد ظاهر، للرفع اليدوي (انظر الطريقة 1) |
| `original-backup/` | النسخة الاحتياطية الأصلية **دون أي تعديل** |

## الطريقة 1: بناء الـEXE على GitHub (لا تحتاج Node.js)

1. أنشئ حساباً مجانياً على https://github.com ثم أنشئ مستودعاً جديداً (**New repository**) واجعله Private.
2. افتح المستودع واضغط **Add file ← Upload files**، ثم اسحب **محتويات** هذا المجلد كلها (ليس المجلد نفسه) وأكّد بـ **Commit changes**.
   - ملف `.github/workflows/build-windows.yml` مجلد مخفي، وقد لا يُرفع بالسحب. تأكد أنه ظاهر في المستودع. إن لم يظهر: اضغط **Add file ← Create new file**، واكتب في خانة الاسم `.github/workflows/build-windows.yml`، والصق فيها محتوى `GITHUB-WORKFLOW-COPY/build-windows.yml`، ثم Commit.
3. افتح تبويب **Actions**. إن ظهرت رسالة تفعيل فاضغط تفعيل. سيبدأ البناء تلقائياً بعد الرفع، أو اختر **Build Windows EXE ← Run workflow**.
4. انتظر نحو 5 إلى 10 دقائق حتى تظهر علامة ✓ خضراء.
5. افتح عملية التشغيل (Run) ونزّل من قسم **Artifacts** الملف **KAMANJAMIX-VIDEO-STUDIO-SETUP**، وهو ملف ZIP بداخله `KAMANJAMIX VIDEO STUDIO SETUP.exe`.
6. نزّل أيضاً **self-test-report** لترى نتيجة الاختبار الذاتي للتطبيق المبني، بما في ذلك حجم ملف التصدير والتحقق من اكتماله.

> قد يظهر الاسم على GitHub بشرطات بدل المسافات. يمكنك إعادة تسميته كما تشاء.

## الطريقة 2: بناء الـEXE على جهازك

يلزم Node.js **للبناء فقط** (من https://nodejs.org نسخة LTS). المستخدم النهائي لا يحتاجه.
1. فك ضغط المشروع في مجلد قصير، مثل `C:\KMX`.
2. انقر مرتين على `BUILD.bat`. يحتاج إنترنت في أول مرة لتنزيل أدوات البناء.
3. تجد النتيجة في مجلد `dist` باسم `KAMANJAMIX VIDEO STUDIO SETUP.exe`.
4. ينفّذ `BUILD.bat` اختباراً ذاتياً للتطبيق المبني ويعرض نتيجته.

## التثبيت والاستعمال

1. شغّل `KAMANJAMIX VIDEO STUDIO SETUP.exe`. التثبيت لمستخدم Windows الحالي ولا يطلب صلاحيات المدير، ويمكنك تغيير مجلد التثبيت.
2. إن ظهرت شاشة **Windows protected your PC**، فهذا لأن المثبّت غير موقَّع برخصة توقيع مدفوعة. اضغط **More info ← Run anyway**.
3. افتح التطبيق من اختصار سطح المكتب أو قائمة ابدأ **KAMANJAMIX VIDEO STUDIO**.
4. الاستعمال كما في النسخة الأصلية: ارفع صورة المغنية وملف MP3 أو اضغط «العرض التجريبي»، ثم اضبط الأدوات.
5. عند «تحميل المقطع» أو «Export Video» تظهر نافذة **حفظ باسم** لاختيار مكان ملف WebM.
6. للإزالة: **الإعدادات ← التطبيقات** ثم KAMANJAMIX VIDEO STUDIO.

## ملاحظات

- التطبيق لا يرسل ولا يستقبل أي بيانات من الإنترنت. يمنع الغلاف كل طلبات الشبكة، والتطبيق نفسه لا يستعمل أي مكتبة أو خدمة خارجية.
- الكشف التلقائي عن الوجه ميزة اختيارية تعتمد على توفر الواجهة في Windows. إن لم تتوفر تظهر رسالة، وحدّد نقطتي الفم والرقبة يدوياً كما في النسخة الأصلية.
- التسجيل والتصدير بصيغة WebM بالوقت الحقيقي. اترك النافذة تعمل حتى ينتهي.

## تشغيل التطبيق للتجربة (للمطوّرين)

```
npm install
npm start
```

## استكشاف الأخطاء

- **فشل `npm install` أو البناء:** تأكد من الاتصال بالإنترنت وأن مجلد المشروع في مسار قصير بلا مسافات أو أحرف عربية. جرّب حذف مجلد `node_modules` وإعادة التشغيل.
- **فشل البناء بسبب إصدار Electron أو electron-builder:** حدّد إصداراً موجوداً في قسم `devDependencies` داخل `package.json` وأعد المحاولة.
- **فشل الاختبار الذاتي:** افتح `dist/smoke-test-result.json` (أو self-test-report من GitHub) وأرسله إليّ.
- **رسالة SmartScreen:** طبيعية لأي برنامج غير موقَّع. التوقيع الرقمي يتطلب شهادة مدفوعة ولم يُضَف.

## استعادة النسخة الأصلية

محتوى `original-backup/KAMANJAMIX-ORIGINAL-BACKUP-untouched.zip` هو أرشيفك الأصلي كما رُفع. الفرق الوحيد بين الأصل والمشروع هنا هو سطر واحد في `js/01-engine-audio-stage.js` والنسخة المنفردة، يجعل حلقة الرسم تبدأ بعد اكتمال التحميل (`window.addEventListener('load', ...)`). وقد كان قبل ذلك يسبب تجمّد المسرح عند بدء التشغيل أحياناً.
